# Predictive Modelling of Student Dropout Risk

This project builds a three-stage supervised learning framework to predict
student dropout risk for an education provider. The models are aligned to
how data becomes available over the student lifecycle:

- **Stage 1** – Application data (pre-enrolment)
- **Stage 2** – Application + engagement (attendance)
- **Stage 3** – Application + engagement + academic performance

## Objectives

- Quantify how predictive power changes from Stage 1 → Stage 2 → Stage 3  
- Compare XGBoost and Neural Network models on accuracy, AUC, precision, recall  
- Assess how early we can reliably identify at-risk students  
- Translate model outputs into a tiered intervention strategy
